# Изменения по миграции JS → PHP

В проекте перенесена прикладная логика с клиентского JS на серверный PHP (кнопки теперь работают через HTML-формы), добавлен учет остатков и внедрено хэширование паролей.

## Что изменено

### 1) Корзина переведена на PHP + Vue2

**Новый файл:** `cart-view.php`

- Добавлена отдельная страница корзины.
- Список товаров в корзине рендерится на **Vue2** (требование выполнено).
- Все действия по кнопкам (`+`, `-`, `Удалить`, `Оформить заказ`) выполняются **через HTML-формы** с отправкой в `cart.php`.
- Vue2 используется только для отображения данных корзины (получение через `cart.php?format=json`).

**Изменения в `cart.php`:**

- Исправлена работа с остатками: используется `product_stock` (вместо `stock`).
- Для переходов разрешен `cart-view.php` с параметрами (`str_starts_with`).
- Добавлен метод `checkout`:
  - проверяет состав корзины;
  - уменьшает остатки по каждому товару;
  - очищает корзину пользователя;
  - пишет flash-сообщение об оформлении.

---

### 2) Управление товарами (добавление/редактирование) переведено на PHP-формы

**Новый файл:** `product-manager-form.php`

- Реализована серверная форма добавления/редактирования товара.
- Доступ только для модератора (`role = 2`).
- В форме добавлено поле **«Количество в наличии»** (`stock`).
- Поддержана загрузка изображения.
- Отправка формы идет в `product-manager.php`.

**Изменения в `product-manager.php`:**

- Добавление/обновление товара переведено на SQL-константы из `queries.php`:
  - `LOAD_NEW_PRODUCT`
  - `UPDATE_PRODUCT`
- ID товара приводится к числу.
- Операции работают с колонкой `product_stock` (через `:stock`).

---

### 3) Отображение остатков в карточках товара

**Изменения в `products-template.php`:**

- Исправлен источник остатков: теперь берется `product_stock`.
- Если остаток 0 — показывается «Нет в наличии», кнопка покупки отключается.
- Если остаток больше 0 — показывается «В наличии: N».

---

### 4) Хэширование паролей

**Изменения в `register.php`:**

- При регистрации пароль сохраняется в БД в виде хэша: `password_hash(..., PASSWORD_DEFAULT)`.

**Изменения в `login.php`:**

- Авторизация переведена на `password_verify`.
- Добавлена совместимость со старыми записями, где пароль уже мог быть сохранен как обычная строка.

---

### 5) SQL-константы

**Изменения в `queries.php`:**

- Добавлена константа:
  - `DECREASE_PRODUCT_STOCK_BY_QTY` — уменьшение остатка на нужное количество при оформлении.

---

## Что нужно изменить в БД (вы делаете сами)

1. В таблице `products` должна быть колонка остатков:
   - `product_stock INTEGER NOT NULL DEFAULT 0`

   Если её нет — добавить именно туда.

2. В таблице `users.password` должен помещаться хэш пароля:
   - обычно `VARCHAR(255)` достаточно.

3. Для старых пользователей с незахэшированными паролями:
   - либо оставить временную совместимость (она уже в коде),
   - либо мигрировать старые пароли на хэш.
